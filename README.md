One line roasting my own AI agent: "My agent burns a thousand tokens an hour to win a five-dollar bounty — then files the loss under 'learnings'." The agent spends a fortune in compute chasing a five-dollar prize, then reframes the loss as a lesson — the roast lands because it is true, and every bounty hunter has filed a loss under "learnings" at least once.

## Run it

```sh
node main.ts
```

This validates the roast (a single line of at most 200 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
